# Privacy and Personal Data

NuciAPI.Client is a .NET client library that facilitates HTTP requests to user-configured REST endpoints. The library itself does not collect, store, or transmit personal data to the project maintainers or any external service. All network traffic is directed exclusively to the API endpoints configured by the application developer.

## 🔎 What This Document Covers

This document describes how NuciAPI.Client at https://github.com/hmlendea/nuciapi.client handles personal data. It covers the library behaviour and verified integrations described below. Where the software is integrated into applications, the application developer controls the data flows and responsibilities described below.

## 🏠 Self-Hosted Deployments

NuciAPI.Client is a library intended to be integrated into applications developed and operated by third parties. This document covers the library's behaviour only. Application developers (instance operators) control their application's configuration, local storage, logs, backups, access controls, retention, and request handling. The library does not send any data to the project maintainers or external services. All HTTP requests are sent exclusively to the base URL and endpoints configured by the application developer.

## 📥 Data We Handle

### Data Provided to the Application

The library does not request or collect personal data. Application developers may pass request objects containing personal data to the library's `SendRequestAsync` methods. The library transmits whatever data is contained in the request object to the configured API endpoint.

### Data Generated or Collected by the Application

The library automatically adds the following headers to each outgoing HTTP request:
- `X-Client-ID` — defaults to `Environment.MachineName` if not overridden via `NuciApiRequestAuthorisationInfo.ClientId`
- `X-Request-ID` — a new GUID generated per request
- `X-Timestamp` — the current UTC timestamp in ISO 8601 format

These headers are transmitted to the configured API endpoint. The library does not log, store, or transmit this data elsewhere.

### Data Received from Integrations

The library receives HTTP responses from the configured API endpoint and deserialises them into the response type specified by the application developer. No personal data is received from third parties or integrations beyond the API responses from the developer's configured endpoint.

## 🧭 Processing and Use

The library processes data for these verified functions:
- Serialising request objects to JSON and transmitting them via HTTP — request object data provided by the application developer
- Adding request metadata headers (`X-Client-ID`, `X-Request-ID`, `X-Timestamp`) — generated by the library
- Attaching authentication headers (`Authorization: Bearer`, `X-HMAC`) — when provided via `NuciApiRequestAuthorisationInfo`
- Deserialising HTTP response bodies into response objects — response data from the configured API endpoint

## 🗄️ Storage, Retention, and Deletion

The library does not persist any data. Request and response objects exist only in memory for the duration of the HTTP request. The `HttpClient` instance may cache connections per standard .NET behaviour. Application developers control all storage, retention, and deletion of data within their applications.

## 🔗 External Processing and Integrations

The library has no built-in external data transfers. All network communication is directed to the base URL and endpoints configured by the application developer. The library depends on the following NuGet packages at runtime, which operate within the application process:
- `Microsoft.AspNetCore.WebUtilities` — query string handling
- `NuciAPI` — request/response base types
- `NuciExtensions` — JSON serialisation extensions
- `NuciSecurity.HMAC` — HMAC token generation

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| Microsoft.AspNetCore.WebUtilities | Query string encoding | Request query parameters | https://www.nuget.org/packages/Microsoft.AspNetCore.WebUtilities |
| NuciSecurity.HMAC | HMAC token generation | Request payload, shared secret | https://www.nuget.org/packages/NuciSecurity.HMAC |

## 🛡️ Data Protection and Security

The library transmits data over HTTP(S) to the configured endpoint. Application developers are responsible for:
- Using HTTPS endpoints to protect data in transit
- Securing authentication credentials (Bearer tokens, HMAC secrets)
- Configuring appropriate timeouts and retry policies
- Validating and sanitising data before passing it to the library
- Protecting logs, backups, and access controls in their applications

The library does not implement encryption, access controls, or audit logging. It does not promise absolute security.
